# Журнал изменений

## 1.0.1 — 2026-10-18

Исправления по скриншоту из реального Chrome с настоящим ChatGPT (см. `docs/05-TESTING.md`).

### Исправлено
* **Очередь останавливалась бы на первом задании с `UI_CHANGED`**: в пустом поле ввода ChatGPT нет кнопки отправки, а проверка требовала её. Теперь нужно только поле ввода; кнопка проверяется после вставки текста.
* **Возможная повторная отправка промпта** (до 3 раз), если ходы беседы не распознаны: ошибка `PROMPT_NOT_ACCEPTED` считалась временной. Теперь — блокировка `SENT_NOT_VISIBLE` без повторов; второй раз задание помечается ошибочным, повтор только по «Повторить ошибки».
* Ключ поиска отправленного сообщения был «первые 60 символов», одинаковые у всех заданий (общий префикс). Теперь — весь короткий текст либо 12 фрагментов по всей длине; допускаются склеенные абзацы и скрытый заголовок «You said:».
* «Сайт: не найден» при открытой вкладке: статус сайта запрашивался только кнопкой и сбрасывался при выгрузке service worker. Теперь панель проверяет сайт сама; различаются «вкладки нет», «мост не отвечает», «версия моста не совпадает».
* Диагностика интерфейса показывала красный ✕ у нормальных состояний; теперь ✓ / – / ? / ✕ по смыслу, с проверкой кнопки отправки и обзором структуры страницы без текста сообщений.

### Добавлено
* Запасной поиск сообщения по тексту и «крупные картинки» как запасной признак изображения, если селекторы ходов/изображений ничего не нашли.
* Дополнительные запасные селекторы ходов, блоков сообщений, поля ввода, кнопок (в том числе русские подписи).
* Мост развёрнут на `promts.vibecods.xyz` на этом сервере (с резервной копией; см. `docs/04-SERVER-SETUP.md`).
* Тесты: юнит 68, e2e 14 (новые: автообнаружение сайта, убранные атрибуты ходов, невидимые сообщения), `npm run test:live-site`; мок ChatGPT ближе к настоящему (нет кнопки отправки в пустом поле, скрытые заголовки ходов).
* Сборка завершается ошибкой при любых предупреждениях esbuild.

## 1.0.0 — 2026-10-18

Первый выпуск.

### Добавлено
* Расширение Chrome MV3: очередь заданий в service worker, конечный автомат (`idle … failed`), атомарное хранение в `chrome.storage.local`, восстановление после выгрузки worker, перезапуска Chrome/расширения, закрытия вкладки и панели.
* Режимы: один персонаж, несколько персонажей, импорт (JSON-экспорт сайта, `rps-batch/1`, JSONL, TXT), тестовое задание.
* Content script ChatGPT на наблюдении интерфейса (снимок DOM → чистый анализ), без слепых нажатий; обнаружение CAPTCHA, потери входа, лимитов, изменения интерфейса, отказов по правилам, нескольких изображений, превью, зависаний, потери сети.
* Сохранение исходных файлов (формат и размер по байтам, SHA-256, защита от дубликатов), папки `Batch_…/Character_NNN/`, `manifest.json`, `character.json`, `prompts.jsonl`, проверка завершения загрузки.
* Русская боковая панель: подключение, пресеты, режимы, подтверждение больших партий, интервал, прогресс по персонажам, повтор ошибок, экспорт журнала (JSON/CSV), аварийная остановка.
* Мост сайта (`source/site-integration`): протокол v1, партия `rps-batch/1` с неизменяемым ядром внешности и отпечатком, тесты (35), скрипт `apply.mjs`, патч.
* Контракт, документация, воспроизводимая сборка с детерминированным ZIP, юнит-тесты (60) и e2e в реальном Chrome (11).

### Известные ограничения
См. `docs/06-LIMITATIONS.md`: неофициальная автоматизация, селекторы не проверены на живом ChatGPT, референс-изображение не реализовано, мост не развёрнут на продакшене.
