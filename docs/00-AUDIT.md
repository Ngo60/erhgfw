### Как сайт сохраняет идентичность (проверено запуском движка)

Эксперимент на реальном движке: паспорт (`Subject`) → 12 кадров в режиме «постоянный персонаж» и 30 кадров в режиме «серия».

* **Неизменны** во всех кадрах: возраст, цвет/длина/тип волос, цвет глаз, оттенок кожи, телосложение, рост, веснушки, особые черты.
* **Меняются по сцене**: причёска (`hairStyle`), макияж (`makeup`), очки (`glasses`, солнцезащитные при солнце). Это сознательное поведение движка, а не ошибка.
* Текст внешности **повторяется в каждом промпте** (рендерер заново описывает один и тот же паспорт).
* Для 50 разных seed получено 50 различных паспортов (но «различны» ≠ «визуально различны»).

Вывод: в контракте внешность разделена на **неизменяемое ядро** (`identity.core`, проверяется отпечатком SHA-256) и **изменяемый стайлинг кадра** (`styling`).
Абсолютной идентичности лица **текстовая генерация не обеспечивает** — это подтверждено ограничением самого подхода (см. `06-LIMITATIONS.md`).

### Что можно переиспользовать / чего не хватает / минимальные изменения

* Переиспользовать целиком: движок, рендерер, пресеты, профиль `gpt-image`, формат экспорта (для импорта).
* Не хватает: машинного канала «сайт → расширение», стабильных идентификаторов задач, паспорта с проверяемым отпечатком, разных персонажей в одной партии.
* Минимальное изменение сайта: **один тонкий модуль** `src/extension-bridge/` (5 файлов, ≈500 строк, без правок движка) + 2 строки в `src/main.tsx`.
  Движок, рендерер и настройки не изменены; на чистом клоне после применения: `typecheck` чист, 452 теста проходят (417 исходных + 35 новых), сборка успешна.

## 2. Расширения-образцы из архива

**Ни одно из расширений не использовано как код**: обе лицензии проприетарные («All rights reserved»), запрещают копирование, модификацию, производные работы и (в первом случае явно) де-минификацию и анализ структуры.
Использованы только наблюдаемые факты из манифестов и общеизвестные сведения; реализация написана с чистого листа (clean-room).

| | ChatGPT Automation Toolkit 1.0.9 (`epifpfomaoammfeiggjgmffipmlecgab`) | ChatGPT Bulk Image Generator 1.0.2 (`pbkklimjkaegllcgfchdegpkgeefnbbj`) |
|---|---|---|
| Лицензия | проприетарная (AutoPlayLabs), использование только из Chrome Web Store, запрет копирования/де-минификации | проприетарная («ChatGPT Image Auto»), запрет копирования/модификации без письменного разрешения |
| Разрешения | `identity`, `activeTab`, `tabs`, `downloads`, `offscreen`, `alarms`, `scripting`, `storage`, `sidePanel`; host: `https://chatgpt.com/*`, **`http://*/*`, `https://*/*`** | `downloads`, `scripting`, `sidePanel`, `storage`, `tabs`; host: chatgpt.com, `*.oaistatic.com`, `*.oaiusercontent.com` |
| Состав | минифицированные бандлы, Firebase, html2canvas — глубокий анализ не проводился (запрещён лицензией) | читаемый код (≈1700 строк): панель, content script, service worker |
| Наблюдения по архитектуре | не оценивалось | цикл очереди работает **в странице панели** (закрыл панель — очередь остановилась); сохранение: `conflictAction: "uniquify"` (при повторе возможны дубли «(1)»), имя = время + 2 слова промпта, расширение по URL/MIME data-URL; картинка берётся из `canvas` и перекодируется в PNG (не исходный файл); готовность — опрос 1,5 с и «стабильно 6 с»; поиск текста лимитов/отказов по всему `body`; случайные паузы по умолчанию 30–90 с между промптами |
| Годится как основа? | нет: лишние разрешения, непрозрачный код, лицензия | нет: лицензия; архитектурные слабости (очередь в UI, нет восстановления, нет проверки загрузки, перекодирование) |

Наблюдаемые факты о странице ChatGPT, на которые опирается селекторный профиль (`source/extension/src/lib/chatgpt-selectors.js`):
поле ввода `#prompt-textarea`, кнопки `data-testid="send-button"`/`"stop-button"`, ходы `section[data-testid^="conversation-turn-"]`.
По открытым публичным сообщениям (GitHub issue `ai-browser-bridge#2`, июнь 2026) изображение генерации лежит **вне** `[data-message-author-role]` и отдаётся с `…/backend-api/estuary/content?id=file_…` (аутентифицированный same-origin URL).
Эти сведения **не проверены мной на живом ChatGPT** (доступа к аккаунту нет) — см. раздел 4.

## 3. Допустимые способы работы с ChatGPT

| Способ | Статус | Комментарий |
|---|---|---|
| Наблюдение и ограниченные действия в **открытой пользователем вкладке** (вставка промпта, «Отправить», «Стоп», чтение результата) | **реализован** | это **неофициальная DOM-автоматизация, а не API**; хрупка к изменению разметки; стоп-проверки и диагностика встроены |
| Официальный API изображений OpenAI (отдельный адаптер) | не реализован | платный, с ключом пользователя; архитектура допускает адаптер, ключ не хранится в коде; решение за пользователем |
| Полуавтоматический режим «каждое изображение — с подтверждением» | не реализован | реализуем поверх тех же шагов; ограничивает скорость, снижает риск |

**Условия использования.** Потребительские условия OpenAI (Terms of Use, редакция от 1 января 2026) запрещают «automatically or programmatically extract data or Output»
(фрагмент подтверждён по цитате в OpenAI Developer Community; страница условий отдала мне HTTP 403, поэтому **текущую редакцию нужно прочитать самостоятельно**).
Автоматизация веб-интерфейса может нарушать условия и привести к санкциям по аккаунту. Расширение:

* не обходит CAPTCHA, лимиты и защитные механизмы — при их появлении **останавливается и уведомляет**;
* не маскирует автоматизацию (нет случайных «человеческих» пауз; интервал фиксированный и настраиваемый, минимум 2 с — это не средство обхода лимитов);
* не хранит пароли и cookie, не отправляет данные третьим лицам;
* не удаляет метаданные происхождения изображений и не изменяет файлы;
* не заявляет «безлимитную генерацию через подписку»: лимиты и стоимость определяет сервис.

Ответственность за соответствие условиям сервиса и за маркировку ИИ-изображений при публикации несёт пользователь.
