# 05. Тестирование: что выполнено и как повторить

Все цифры ниже получены **реальными запусками** в этом репозитории (Node 24, Chrome for Testing 155, Linux). То, что не запускалось, перечислено отдельно.

## Команды

```bash
npm ci
npm run build          # сборка + проверка манифеста и бандлов + детерминированные ZIP
npm test               # юнит-тесты расширения (node:test, без браузера)
npm run test:e2e       # сборка + реальный Chrome + мок ChatGPT + собранный сайт с мостом
node tests/e2e/mock/selftest.mjs        # самопроверка мока ChatGPT (реальный Chrome, без расширения)
# сайт (после применения моста): npm run typecheck && npm test && npm run build && npm run smoke
```

E2E ищет Chrome в `CHROME_PATH`, затем в типовых путях; собранный сайт — `SITE_DIST` (см. `.env.example`). Windows/macOS: тесты на этих ОС **не запускались** (код кроссплатформенный, но проверен только на Linux).

## Результаты

| Набор | Результат |
|---|---|
| Юнит-тесты расширения | **60 из 60** проходят (≈9 с) |
| E2E в реальном Chrome | **11 из 11** проходят (≈3 мин) |
| Самопроверка мока ChatGPT | 32 из 32 |

## Сценарии из ТЗ → тесты

| Сценарий | Где проверен |
|---|---|
| 1 персонаж × 3 фото | юнит `orchestrator.core`; **e2e через интерфейс панели** (файлы `001–003.png`, `prompts.jsonl`, `manifest.json`, `character.json`, текст отправки = промпт сайта) |
| 1 персонаж × 20 фото | юнит (20 файлов, ротация беседы на 12-м кадре) |
| 3 персонажа × 5 фото | юнит (15 файлов, 3 беседы, персонаж не размазан по беседам); e2e 2 × 2 (папки `Character_001/002`, 2 беседы) |
| Массовый режим (нагрузка) | юнит 50 × 30 = 1500 заданий в виртуальном времени: каждое отправлено ровно один раз, 1500 уникальных файлов и текстов, 50 бесед |
| Прерывание после отправки | юнит (выгрузка worker в `waiting`/`submitting`); **e2e: принудительное завершение service worker (CDP) посреди генерации** — без повторных отправок |
| Закрытие popup/панели | e2e: панель закрыта на 15 с, очередь продолжилась |
| Перезапуск Chrome | e2e: Chrome закрыт и запущен с тем же профилем, состояние сохранено, после «Продолжить» нет повторов; юнит `browser-startup` → пауза |
| Потеря сети | юнит: ожидание без расхода попыток; затем `OFFLINE` |
| Ошибка загрузки | юнит: прерванная загрузка, несовпадение размера, исчерпание попыток, повтор без новой генерации |
| Отсутствие авторизации | юнит + e2e (`AUTH_REQUIRED`, продолжение после входа) |
| Изменённый DOM | юнит + e2e (`UI_CHANGED`, ничего не отправляется, диагностика «не ок») |
| Лимит сервиса | юнит + e2e: остановка, **нет авто-повторов**, после «Продолжить» повторная отправка |
| CAPTCHA | юнит + e2e: остановка, ничего не отправляется |
| Одинаковые имена | юнит: 1500 уникальных путей; `conflictAction: overwrite`, нет «(1)»; повторная загрузка не создаёт копий |
| Дублированный ответ API | юнит: повторная выдача партии не создаёт заданий; идемпотентный `batch_id` (тест моста); дубликат содержимого (SHA-256) отклоняется |
| Метаданные соответствуют промптам | юнит + e2e: `prompts.jsonl` ↔ промпт сайта ↔ отправленный текст ↔ файл |
| Два изображения вместо одного | юнит (все политики) + e2e (`MULTIPLE_IMAGES`, смена политики, повторная загрузка **без** новой генерации) |
| Зависание, текст без изображения, превью-размер, баннер ошибки, отказ по правилам, подряд 3 отказа | юнит |
| Подтверждение больших партий, лимит 1500, настройки, изоляция сообщений | юнит |

Дополнительно проверено в реальном Chrome: манифест MV3 принят без ошибок, набор разрешений минимален, мост реального собранного сайта отвечает (`hello`, пресеты, сборка партии движком), `credentials: include` у `fetch` service worker передаёт cookie сессии (мок отвечает 401 без неё).

## Что НЕ проверялось (честно)

* **Живой ChatGPT.** Нет доступа к аккаунту и к chatgpt.com из среды выполнения. Селекторы и признаки состояния проверены только на моке, смоделированном по публичным описаниям DOM и наблюдаемым селекторам; соответствие реальному интерфейсу 2026 года **не подтверждено**.
* Реальные лимиты, CAPTCHA и тексты отказов ChatGPT (проверены на шаблонных текстах).
* Развёртывание моста на `promts.vibecods.xyz` (продакшен не менялся).
* Windows/macOS, Chrome Stable (использован Chrome for Testing), реальное поведение `runtime.onStartup` при штатном перезапуске (тест принимает оба исхода и проверяет отсутствие дублей).
* Системные уведомления и закрепление боковой панели (панель в e2e открыта как страница вкладки; логика та же).
* Изображения реального размера (мок отдаёт ≈ 47 КБ) и длительная работа сверх 1500 виртуальных заданий.
