# 06. Ограничения и реализуемые альтернативы

| Ограничение | Следствие / альтернатива |
|---|---|
| Взаимодействие с ChatGPT — **неофициальная DOM-автоматизация** открытой вкладки, а не API | Может противоречить условиям OpenAI («automatically or programmatically extract data or Output»; текущую редакцию читайте на openai.com), риск санкций по аккаунту — на пользователе. Разметка меняется без предупреждения: нужна диагностика и обновление `chatgpt-selectors.js`. Альтернативы: официальный Images API как отдельный адаптер (платный, не реализован); режим «подтверждение каждого кадра» (не реализован) |
| **Селекторы ChatGPT не проверены на живом аккаунте** (у агента нет доступа к chatgpt.com) | Логика проверена в реальном Chrome против **мока**, смоделированного по публичным описаниям DOM. Перед большими партиями обязательно «Проверить интерфейс ChatGPT» и «Тестовое задание» |
| Запасной поиск сообщения по тексту и «крупные картинки» как запасной признак изображения | Включаются только если обычные селекторы пусты; проверены на моке, на живом ChatGPT не проверялись; при неудаче очередь останавливается, а не повторяет |
| Диагностика вставляет символ «.» в **пустое** поле ввода, чтобы увидеть кнопку отправки, и сразу удаляет его | Если в поле есть ваш черновик, проверка пропускается (`?`). Отправка не выполняется |
| Текстовая генерация не гарантирует идентичное лицо | Реализованы: неизменяемое ядро, повтор описания, беседа на персонажа, ротация, различие персонажей, ручная проверка. Референс-изображение не реализовано (причины в `01-ARCHITECTURE.md §4`) |
| `chrome.downloads` пишет только внутрь папки загрузок | Другой каталог — через `chrome://settings/downloads`. ZIP изображений не делается (хранение гигабайт в расширении недопустимо): архивируйте папку партии; журнал и метаданные экспортируются |
| Файл проверяется по размеру, формату и `exists` браузера; **содержимое сохранённого файла повторно не хэшируется** (расширение не читает файловую систему) | SHA-256 вычисляется по полученным байтам; несовпадение размера → повтор |
| Фоновая вкладка ChatGPT замедляется браузером | Держите отдельное окно; наблюдение продолжается, но медленнее |
| Service worker выгружается | Состояние в `chrome.storage.local`, watchdog 30 с; в момент выгрузки возможна задержка до 30 с |
| Перезапуск Chrome/обновление расширения ставит очередь на паузу | Намеренно: без действия пользователя автоматизация не возобновляется |
| Лимиты, CAPTCHA, вход, отказ по правилам | Остановка/ошибка задания без обхода; три отказа подряд останавливают очередь |
| Мост установлен на `promts.vibecods.xyz` на этом сервере (`04-SERVER-SETUP.md`, там же резервная копия и откат); в git сайта изменения **не закоммичены** | Для другого развёртывания сайта — `apply.mjs`; без моста работает импорт файла (режим C) |
| Только `chatgpt.com` (не `chat.openai.com`), только один язык интерфейса ChatGPT протестирован (английский) | Русские тексты лимитов/отказов в шаблонах есть, но не проверены |
| Батарейка/спящий режим ПК, закрытая крышка, потеря сети >15 мин | очередь останавливается, состояние сохраняется |
| Лимиты размера: ≤ 1500 заданий в партии, ≤ 50 персонажей, ≤ 100 кадров на персонажа | задаются мостом и проверяются расширением |

Ответственность: использование ИИ-изображений (маркировка, права, недопущение обмана и выдачи за реальные фотографии людей) — на пользователе.
Сайт генерирует только описания вымышленных совершеннолетних персонажей; расширение не удаляет метаданные происхождения и не модифицирует файлы.
