# 03. Установка и использование

## Требования

* Google Chrome **116+** (десктоп). Тестировалось на Chrome for Testing 155 (Linux).
* Вы вошли в ChatGPT и сами выбрали режим/модель, где доступна генерация изображений. Лимиты и стоимость определяет сервис.
* Node.js **22+** нужен только для сборки из исходников.

## Установка (готовая сборка)

1. Откройте `chrome://extensions`, включите **Режим разработчика**.
2. **Загрузить распакованное расширение** → папка `dist/chrome-unpacked` (или распакуйте `dist/realphoto-chatgpt-batch-extension-1.0.1.zip`).
3. Закрепите значок. Клик по значку открывает **боковую панель** на русском языке.

## Обновление уже установленного расширения

1. `chrome://extensions` → на карточке расширения нажмите **⟳**. Папку не переименовывайте и не переносите.
2. Во вкладках `https://promts.vibecods.xyz/` и `https://chatgpt.com/` нажмите **Ctrl+F5** (старая страница не знает о новой версии расширения/моста).
3. Версия на вкладке «О расширении» должна совпасть с версией из `CHANGELOG.md`.

## Первый запуск

1. В **этом же окне** Chrome откройте `https://chatgpt.com/` (войдите в аккаунт) и `https://promts.vibecods.xyz/`.
2. В панели нажмите **«Проверить интерфейс ChatGPT»** — должно быть «найдено» для поля ввода и кнопки отправки.
3. Сначала выполните **«Тестовое задание»**: одно изображение в отдельную папку `Test_…`. Убедитесь, что картинка сохранилась и похожа на ожидаемую.

### Как читать «Проверить интерфейс ChatGPT»

| Значок | Смысл |
|---|---|
| ✓ найдено | элемент распознан (для кнопки отправки — после ввода символа в пустое поле: символ тут же удаляется, отправка не выполняется) |
| – нет (это нормально) | элемент появляется только в определённый момент: кнопка «Стоп» — во время генерации, ходы беседы — в непустой беседе |
| ? не проверено | проверку нельзя было выполнить безопасно (например, в поле ввода есть ваш черновик — очистите его и повторите) |
| ✕ не найдено / ОБНАРУЖЕНО | проблема: нет поля ввода или кнопки отправки, или вход/CAPTCHA, или в беседе с названием не распознано ни одного сообщения |

![диагностика интерфейса ChatGPT](screenshots/panel-diagnose.png)

Внизу отчёта — заметки с структурой страницы (теги, `data-testid`, роли, крупные изображения) без текста ваших сообщений. Если расширение не распознаёт ChatGPT, этот отчёт — то, что нужно приложить к описанию проблемы.

## Режимы

* **Один персонаж** — число кадров (10/15/20/30 или своё). Ядро внешности постоянно, меняются сцены, ракурсы, одежда, причёска.
* **Несколько персонажей** — число персонажей (до 50) × кадров (до 100); у каждого свой паспорт, своя беседа ChatGPT и своя папка.
* **Ручная/импортированная очередь** — файл JSON-экспорта сайта, партия `rps-batch/1`, JSONL (`{"prompt": "...", "character": "Имя"}`), TXT (экспорт сайта или «промпт на строку»).
  Работает **без изменений сайта**.

«Сформировать очередь» вызывает движок сайта (нужна вкладка сайта с установленным мостом — `04-SERVER-SETUP.md`). Если мост не развёрнут, используйте импорт файла.
Партии больше 50 изображений требуют подтверждения (флажок), больше 300 — ввода числа; больше 1500 запрещены.

## Управление

**Старт · Пауза** (после текущего изображения) **· Продолжить · Остановить · Повторить ошибки** (перекачивает уже сгенерированное без новой генерации, если возможно) **· Экспорт журнала** (JSON/CSV) **· АВАРИЙНАЯ ОСТАНОВКА** (немедленно прекращает работу, нажимает «Стоп» в ChatGPT и не возобновляется без вашего действия).
Клик по готовой ячейке кадра показывает файл в папке. Закрытие панели очередь **не останавливает**.

## Куда сохраняются файлы

`<папка загрузок Chrome>/<«Папка» из настроек, по умолчанию ChatGPT-Images>/Batch_ГГГГ-ММ-ДД_NNN/Character_001/001.png` + `character.json`, `prompts.jsonl`, `manifest.json`.
Расширение зависит от реального формата. Другой диск/каталог выбирается в `chrome://settings/downloads` (расширение не получает произвольного доступа к файловой системе).

## Рекомендации

* Держите вкладку ChatGPT в **отдельном окне**, не сворачивайте и не открывайте вторую вкладку ChatGPT: фоновые вкладки браузер замедляет, наблюдение становится медленнее.
* Не меняйте беседу вручную во время работы. Для паузы пользуйтесь кнопкой «Пауза».
* Интервал по умолчанию 5 с (минимум 2 с) — это пауза после сохранения, **не способ обхода лимитов**. При предупреждении об ограничении очередь остановится сама.
* Автоматизация веб-интерфейса может противоречить условиям сервиса — прочитайте `06-LIMITATIONS.md`.

## Если в панели «Сайт: …»

| Сообщение | Причина и действие |
|---|---|
| «вкладка не открыта» | откройте `https://promts.vibecods.xyz/` в этом же окне Chrome; панель найдёт её сама через несколько секунд |
| «открыт, но мост не отвечает» | вкладка загружена до установки моста на сайт или это старая версия страницы — **Ctrl+F5**; если не помогло, мост не установлен (`04-SERVER-SETUP.md`), используйте импорт файла |
| «версия моста не совпадает» | обновите сайт или расширение |

## Если очередь остановилась

| Сообщение | Что делать |
|---|---|
| CAPTCHA | пройдите проверку вручную в ChatGPT → «Продолжить» |
| Нужен вход | войдите → «Продолжить» |
| Лимит | дождитесь сброса → «Продолжить» (повтор будет с новой беседы) |
| Промпт отправлен, но не виден в беседе (`SENT_NOT_VISIBLE`) | расширение **не отправляет повторно**. Откройте беседу: если изображение создано — сохраните его вручную, затем «Продолжить» (поиск повторится) или «Повторить ошибки». Нужна диагностика: см. выше |
| Интерфейс не распознан | «Проверить интерфейс ChatGPT»; нужно обновить `chatgpt-selectors.js` и пересобрать |
| Вкладка закрыта/не найдена | откройте ChatGPT → «Продолжить» (отправленный промпт будет найден, дубликата не будет) |
| Очередь на паузе после перезапуска | «Продолжить» |

## Обновление и пересборка

```bash
npm ci
npm run build      # dist/chrome-unpacked + ZIP расширения + ZIP исходников (результат детерминирован)
npm test           # юнит-тесты
npm run test:e2e   # реальный Chrome + мок ChatGPT + собранный сайт (см. 05-TESTING.md)
```

После пересборки нажмите «Обновить» у расширения в `chrome://extensions`. Состояние очереди сохраняется; сразу после обновления очередь стоит на паузе до «Продолжить».
