# Пакетная генерация изображений в ChatGPT по промптам promts.vibecods.xyz

Расширение Chrome (Manifest V3), которое берёт готовые промпты у генератора **RealPhoto Prompt Studio** (`promts.vibecods.xyz`) и по очереди выполняет их в **вашей открытой вкладке ChatGPT**:
одиночные и массовые серии, отдельные стабильные профили персонажей, сохранение по папкам, пауза/продолжение, восстановление после сбоев. Интерфейс на русском.

> ⚠️ Это **неофициальная DOM-автоматизация** вашей вкладки, а не API. Она может противоречить условиям использования OpenAI; расширение **не обходит** CAPTCHA, лимиты и защиты (при их появлении останавливается и уведомляет).
> Идентичность лица при генерации по тексту **не гарантируется**. Подробнее — `docs/06-LIMITATIONS.md`.

## Быстрый старт

> После обновления расширения: `chrome://extensions` → кнопка ⟳ на карточке, затем **Ctrl+F5** во вкладках сайта и ChatGPT. Версия сборки видна на вкладке «О расширении» (сейчас 1.0.1).

1. `chrome://extensions` → Режим разработчика → **Загрузить распакованное** → `dist/chrome-unpacked`.
2. Откройте в одном окне `https://chatgpt.com/` (вы вошли) и `https://promts.vibecods.xyz/`.
3. Клик по значку → панель → «Проверить интерфейс ChatGPT» → «Тестовое задание» → при успехе «Сформировать очередь» → «Старт».

Мост на стороне сайта (`source/site-integration`) нужно установить один раз (`docs/04-SERVER-SETUP.md`); до этого работает **импорт файла** (JSON/JSONL/TXT-экспорт сайта).

## Состав репозитория

```text
source/extension/        исходники расширения (service worker, content scripts, панель, i18n, манифест)
source/site-integration/ мост для сайта: модуль, тесты, скрипт apply.mjs, патч
source/contract/         описание контракта и контрактные фикстуры (реальный вывод движка сайта)
dist/chrome-unpacked/    готовая распакованная сборка;  dist/*.zip — ZIP расширения и ZIP исходников
docs/                    аудит, архитектура, контракт, установка, настройка сайта, тесты, ограничения
tests/                   юнит-тесты, e2e (реальный Chrome), моки ChatGPT и сайта
scripts/                 воспроизводимая сборка, проверка манифеста, детерминированный ZIP, генератор иконок
```

## Сборка и проверка

```bash
npm ci
npm run build       # → dist/ (детерминированно)
npm test            # юнит-тесты (68)
npm run test:e2e    # реальный Chrome: нужен CHROME_PATH и SITE_DIST (см. .env.example)
```
