# Контракт

Нормативное описание — `docs/02-CONTRACT.md`. Здесь лежат **контрактные фикстуры** (`fixtures/`) — реальный вывод движка сайта; на них проверяются и мост сайта, и расширение:

| Файл | Что это | Кем используется |
|---|---|---|
| `bridge-batch-2x3.json` | партия `rps-batch/1`, собранная мостом на реальном движке (2 персонажа × 3 кадра, seed `RP-FIXTURE1`) | `tests/unit/lib.data.test.mjs` (приём, подделки, импорт) |
| `site-export-3.json` / `site-single.json` | JSON-экспорт сайта (`entriesToJson` / `entryToJson`) | импорт (режим C) |
| `site-export-3.txt` | TXT-экспорт сайта (`entriesToTxt`) | импорт (режим C) |

Фикстуры получены скриптом на движке сайта (`runBatch`, `renderScenario`, `buildBatch`). При изменении формата партии обновите их и тесты обеих сторон.
